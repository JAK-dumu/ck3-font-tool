# CK3 中文字体替换器

把任意中文字体拖进来 → 按游戏内字号预览 → 一键生成可安装的《十字军之王 III》字体 mod。

纯前端、单页面、零依赖、完全离线运行——字体文件只在你的浏览器里处理，绝不上传。

**在线使用**：https://jak-dumu.github.io/ck3-font-tool/

## 使用

1. 把 `.ttf` / `.otf` 字体文件拖进页面（可多选）
2. 在「分配槽位」为各槽位选字体，或打开「自动分配」按文件名推断
3. 「预览效果」按游戏内实机字号展示四大文字区（标题/地图 → 加粗 → 正文 → 数字/西文）
4. 「生成字体 mod」下载 zip 解压到游戏 mod 目录，或直接授权写入（Chromium 内核浏览器）

## 六个槽位

| 槽位 | 游戏内对应 |
|---|---|
| 标题字体 | 剧本名、头衔名、界面大标题 |
| 地图字体 | 领地名与人物名标签 |
| 正文·常规 / 加粗 | 事件正文、tooltip、界面文字及其强调 |
| 正文·斜体 / 粗斜体 | 引号风格化文本（默认锁定跟随正文，可用「斜体跟随」开关解锁） |
| 数字 / 西文 | 跟随所在槽位的西文部分，可开关「拉丁数字保持原版」防风格突变 |

## 为什么行距不会乱

CK3 按字体自带的垂直度量（hhea / OS-2）计算行距，不少楷体的原生行距只有 1.05em（原版约 1.4–1.5em），直接替换会出现两行紧贴、文字骑线。本工具在打包时**自动把所选字体的垂直度量按比例校正到其取代的原版字体数值**——只改度量、不改字形，行推进与原版分毫不差，无需修改任何游戏 gui 文件。

## 其他特性

- **缺字提示**：载入字体后自动比对预览样张的字符覆盖，缺字会标出（缺的字游戏内会由兜底字体渲染）
- **自动分配**：按文件名识别（文楷→正文、臻楷→加粗、汇迹/Cooper→标题与地图……），未识别的字体按顺序填空槽，最坏情况也有产出
- **直写 mod 目录**：授权一次目录后两段式写入（选目录 → 确认 → 落盘），支持一键移除
- **浅色 / 深色主题**：跟随系统并可手动切换

## 浏览器支持

- Chromium 内核（Edge / Chrome）：全功能，含直写游戏 mod 目录
- Firefox / Safari：除「发送到游戏 mod 目录」外全部可用，产出走下载 zip

## 字体授权

页面预览使用的三款字体均为 SIL Open Font License 1.1 开源字体的子集（仅含界面字符），授权与来源见 [FONTS.md](FONTS.md)。你自己拖入的字体由你负责确认再分发条款——工具只在你本机打包，不做任何上传。

## 开发

```bash
node test_dom.js          # 62 项逻辑回归（槽位链、fonts.font 生成、度量补丁、cmap 解析、zip 打包）
python subset_page_fonts.py   # 页面文案增改后重跑：重新子集化 fonts_page/ 三字体
```

页面结构：`index.html`（UI 层）+ `design-tokens.css`（样式变量）+ `fonttool_core.js`（纯逻辑，浏览器与 Node 双端）。改逻辑必须跑测试；改文案必须重跑子集脚本。
